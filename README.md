# CAB201_Revision

Short, example-first notes on writing clean object-oriented code in C#.

## Reading order

1. [OOP](OOP.md) - the 4 pillars (Encapsulation, Abstraction, Inheritance, Polymorphism) and the anemic model.
2. [SOLID](SOLID.md) - 5 principles for code that's easy to change.
3. [MVC](MVC.md) - splitting an app into Model, View and Controller. Fat model, thin controller.
4. [Scenario](Scenario.md) - everything together: in-memory DB now, relational DB later, using repositories, a service and DI.
5. [Cohesion](Cohesion.md) - how well the parts inside one class belong together. The 7 types, worst to best.
6. [Coupling](Coupling.md) - how much classes depend on each other. Tight vs loose, and the 5 types, worst to best.
7. [MCQ](mcq.md) - 48 practice questions: constructors and inheritance, ref vs out, overloading vs overriding, SOLID, cohesion, coupling and case studies.

> [!TIP]
> The diagrams use mermaid. GitHub renders them out of the box. In VS Code, install the "Markdown Preview Mermaid Support" extension.
